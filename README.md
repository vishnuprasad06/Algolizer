## About

Algolizer makes core computer science concepts easier to understand through interactive visualizations. Explore how algorithms work, follow operations step by step, and experiment with different inputs.

## Learning Modules

- **Sorting Algorithms** — visualize sorting operations step by step.
- **Graph Algorithms** — explore graph traversal and shortest-path concepts.
- **Data Structures** — understand how common data structures organize information.
- **Digital Electronics** — explore digital logic and related concepts.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Lucide React

## Run Locally

**Prerequisite:** Node.js

1. Clone the repository:
   ```bash
   git clone https://github.com/vishnuprasad06/Algolizer.git
   cd Algolizer
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```
